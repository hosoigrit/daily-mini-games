# 別チャットに渡す評価依頼

このプロンプトと1つの事件資料だけを新規チャットに渡してください。別の事件資料、ゲームURL、既存の会話、採点資料は渡さないでください。同じチャットを次の事件に再利用しません。

## プロンプト本文

あなたは初めてこの推理ゲームを読む独立評価者です。添付された1件の事件資料が、告発前にプレイヤーが読める情報です。この資料だけを使って判断してください。検索や外部資料の参照は行わず、与えられていない設定を補完しないでください。

1. 資料から特定できる犯人・犯行時刻（または時間帯）・手口を示してください。特定できない箇所はその理由を書いてください。
2. 告発に使う証拠を2〜4件、表示番号と見出しで挙げ、各カードが何を証明するかと、事件の前提からどの推論が成立するかを説明してください。
3. 他の容疑者2人について、個別に除外根拠を挙げてください。別の実行者・時刻・経路でも公開情報を満たす反例があれば、その筋道を示してください。
4. 同じ結論を立証できる別の証拠の組合せを挙げてください。見つからなければその旨を記録してください。ゲームが実際に受理するかは、ここでは未検証です。
5. ミスリードが公平か、前提不足や時系列の矛盾がないかを述べてください。難易度と面白さは各1〜5で、理由を添えてください。これは資料を読んだ印象として記録し、実プレイの体感や解説後の納得感は未評価としてください。

回答を「結論」「立証と他2人の排除」「代替証拠」「残る反例・公平性」「評価」に分けてください。推論は他の人が資料で確認できるよう、要点を証拠に紐づけてください。
