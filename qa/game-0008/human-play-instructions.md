# 初見推理テスト・評価者用

進行役から受け取ったゲームURLを開き、割り当てられた事件を1回プレイしてください。表示された事件の前提、証言、証拠だけを使ってください。検索や他の参加者への相談は行わず、プレイ中はゲーム画面と下の記録欄を使います。評価対象はゲームです。解けない場合や候補が複数残る場合も、そのまま記録してください。

## 流れ

1. 開始時刻を記録し、事件の前提と証言、証拠を読みます。告発やヒントを見る前に、下の「告発前」を書き、進行役へ提出してください。
2. 自分の第一候補と証拠で告発します。結果と時刻を記録します。その後の再告発やヒントは必要なら使えます。ヒント・真相開示の使用と時刻を残してください。
3. 別の組合せが成立すると思ったら、告発前にその根拠も書きます。試行は進行役の案内に従い、証拠を変えた別提出として記録してください。
4. 真相や解説を確認した後、説明で納得できた点、解説後も残った疑問、楽しかった点を記録してください。

記録には [回答テンプレート](human-response-template.md) を使ってください。進行役は対象資料のみを渡し、回答は参加者と進行役の間で管理してください。
