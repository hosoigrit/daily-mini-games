## RC6 現行入力・音声契約
ドラッグはpointerdownから現在までの最大ユークリッド変位≥6 CSS px。pointerup位置も判定し、途中でdrag化したらtapに戻さない。盤面の実形状までの画面座標最短距離≤8 CSS pxを選択許容とし、最短距離、同値時は04の正規キー順。fixedは編集対象外。盤面変換はCSS表示矩形を960×720論理へ線形変換、DPR上限2は描画だけ。200%文字拡大では折返し・縦スクロールを許容しMust操作の到達不能を禁止。通常320pxでは主要44×44 CSS px以上・横overflowなし。板音は同じ有効接触episodeで最後に発音許可した角度との差の絶対値≥5°かつ直近SE05から250ms以上で発音要求。episode終了で角度参照をリセット、最小間隔は実験内で維持。ミュート・旧run・停止で再生禁止。音声時計はゲーム判定に影響しない。
