# Codex向け：Game #0007 読み取り限定の実装前調査（実装禁止）

対象リポジトリ：`hosoigrit/daily-mini-games`

これは「おてんきベーカリー」設計承認後の**事前調査だけ**を依頼する文書です。**ユーザーはまだ実装を許可していません。**

## 絶対禁止
- コード・ドキュメント・設定・テストファイルの作成／編集／削除
- `git checkout -b`などのブランチ作成、コミット、Push、PR作成、マージ、Pages公開
- 依存パッケージの導入、設定変更、外部通信を伴う状態変更、課金
- インフラ・CIの設定変更、既存ゲームの変更

## 読み取り限定の依頼内容
1. `AGENTS.md` と `README.md` を読み、運用ルールを列挙する。
2. リポジトリの現在の構成、`games/0005_hitofude-delivery` 等から、既存コード規約、テスト方式、`docs/`公開の仕組みを調べる。
3. `node --version`・`npm --version`・`git status --short`を読み取り、互換性上の懸念があれば指摘する。ただしコマンド実行が副作用を持たないことを確認する。
4. 本パックの承認済み設計とリポジトリ現況の差異、隠れた依存関係、実装時の注意点を報告する。
5. 実装フェーズ分割と推奨テストコマンドを提案する。**実行・変更はしない**。

## 報告書形式
- リポジトリの基準ブランチ／HEAD SHA／作業ツリー状態
- 読み取ったファイル・調査コマンド
- 既存の規約やテスト基盤
- 設計との矛盾（重大／中／軽微）
- 追加確認が必要な事項と実装着手条件
- 変更ファイル：**0件** と記載（実際に0件であることを確認）

注意：調査が完了しても実装へ自動的に移行しない。
