## 1. 判定ルール

各ケースを次のいずれかで記録する。

- **確認できました**：記載された操作をすべて行い、期待結果と一致した。
- **不具合あり**：期待結果と異なる。発生手順、端末、向き、表示内容を記録する。
- **未確認**：一部でも実施していない、または判定できなかった。

注意事項：

1. エミュレーション結果をAndroid／iPad／iPhone実機のPASSとして扱わない。
2. iPad Safariの結果をiPhone Safariの結果として扱わない。
3. 機種、OS、ブラウザ版、確認日、確認者を必ず記録する。
4. スクリーンショットや動画は任意。秘密情報や他サイトの情報が写らないようにする。
5. 不具合が1項目でもあれば、そのケース全体を「確認できました」にしない。

### 2-2. ローカルHTTP配信

`file://`ではなくローカルHTTPで開く。PowerShellでゲームディレクトリへ移動する。

```powershell
Set-Location 'C:\Users\yukit\Desktop\学習\40_生成AI\99_tool\Codex\10_ゲーム開発\games\0002_light-panels'
```

PCだけで確認する場合は、次のNodeコマンドで`127.0.0.1`限定のサーバーを起動する。

```powershell
node -e "const h=require('node:http'),f=require('node:fs'),p=require('node:path'),r=process.cwd(),t={'.html':'text/html; charset=utf-8','.css':'text/css; charset=utf-8','.js':'text/javascript; charset=utf-8','.mjs':'text/javascript; charset=utf-8'};h.createServer((q,s)=>{const n=decodeURIComponent(new URL(q.url,'http://127.0.0.1').pathname).replace(/^\/+/, '')||'index.html',x=p.resolve(r,n);if(x!==r&&!x.startsWith(r+p.sep)){s.writeHead(403);s.end('Forbidden');return}f.readFile(x,(e,d)=>{if(e){s.writeHead(404);s.end('Not found');return}s.writeHead(200,{'Content-Type':t[p.extname(x)]||'application/octet-stream','Cache-Control':'no-store'});s.end(d)})}).listen(4174,'127.0.0.1',()=>console.log('http://127.0.0.1:4174/index.html'))"
```

PCブラウザで次を開く。

```text
http://127.0.0.1:4174/index.html
```

スマートフォン／タブレットで確認する場合は、PCと端末を同じ信頼できるプライベートネットワークへ接続する。外部公開、ルーターのポート転送、パブリックネットワークでの利用は行わない。LAN配信が必要になった時点でCodexへ起動を依頼するか、人間が安全なローカルサーバーを準備する。Windowsのファイアウォール確認が表示された場合は、パブリックネットワークへ許可しない。

テスト終了後はサーバーを起動したPowerShellで`Ctrl+C`を押して停止する。

## 3. テスト用解答手順

行・列は画面の上・左から1始まり。順番が前後しても同じ解になるが、テストでは表の順に押す。

| ステージ | 押すパネル（行,列） | 期待手数 |
| --- | --- | ---: |
| S01 | `(2,2)` | 1 |
| S02 | `(1,1)` → `(3,3)` | 2 |
| S03 | `(1,2)` → `(2,1)` → `(3,3)` | 3 |
| S04 | `(2,2)` → `(3,3)` → `(1,4)` | 3 |
| S05 | `(1,1)` → `(1,4)` → `(4,1)` → `(4,4)` | 4 |
| S06 | `(1,2)` → `(2,4)` → `(3,1)` → `(4,3)` → `(2,2)` → `(3,3)` | 6 |

## 4. 共通の目視ポイント

すべての端末で次を確認する。

- 横スクロールが発生しない。
- 盤面、ステージ番号、手数、主要ボタンが読める。
- 点灯は黄色・発光・`ON`、消灯は暗色・`OFF`で、色だけに依存しない。
- 1回押すと手数が1だけ増える。
- 点灯状態と手数が同時に更新される。
- クリア後に旧盤面を押しても手数や記録が変わらない。
- 縦横回転だけでは盤面や手数が消えない。
- ページ再読込では途中盤面と途中手数が破棄され、保存済み進捗だけが復元される。
- 操作不能、二重操作、誤スクロール、文字選択、表示欠けがない。

## 5. PC Chrome：TC-035

### 操作

1. 初期状態でChromeからURLを開く。
2. タイトル、3行のルール、「S01を始める」「ステージ一覧」が表示されることを確認する。
3. 「ステージ一覧」をクリックし、S01だけが操作可能でS02〜S06がロック中であることを確認する。
4. タイトルへ戻り、「S01を始める」をクリックする。
5. S01の中央 `(2,2)` をマウスで1回クリックする。
6. 1手でクリアし、S02が解放されたことを確認する。
7. 「次へ」でS02を開始する。
8. 任意の同じパネルを2回クリックし、盤面が開始時に戻って手数が2になることを確認する。
9. 「やり直し」を押し、手数0と初期盤面へ戻ることを確認する。
10. テスト用解答でS02をクリアする。
11. 「一覧へ」でS01とS02を再挑戦でき、S03が新たに解放されていることを確認する。
12. ページを再読み込みし、タイトルへ戻ること、解放状況とベスト手数が残ることを確認する。

### 期待結果

- クリック1回につき1操作。
- S01は1手、S02は2手でクリアできる。
- やり直し、順次解放、一覧、保存復元が正常。
- 横スクロールや操作不能がない。
