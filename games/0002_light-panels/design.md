# 基本設計書：0002 ひかりのパネル（実装配置版）

> 正本：`0002_light-panels_design_draft_v0.1.md`。2026-11-16に全文、DD-01〜DD-10、固定6ステージを人間承認済み。本ファイルは実装ディレクトリで参照しやすいよう、承認済み設計の実装契約を抜粋したものであり、仕様変更ではない。

## 1. 設計概要

- HTML／CSS／素のJavaScript、ブラウザ標準ES Modules、Node標準テストを使用する。
- 盤面ロジック、固定ステージ、保存処理、UI調停を分離する。
- 盤面の正本はJavaScriptの二次元配列とし、DOMの見た目から状態を読み戻さない。
- 外部ライブラリ、外部通信、外部素材、ビルド処理は導入しない。
- PC、320 CSS px以上のスマートフォン、縦横表示、キーボード、支援技術へ配慮する。

## 2. システム構成

| ファイル | 責務 |
| --- | --- |
| `index.html` | 5画面、操作要素、状態通知の土台 |
| `styles.css` | CSS Grid、点灯表現、フォーカス、レスポンシブ表示 |
| `game.js` | UIイベント、画面状態、描画、進捗更新の調停 |
| `game-logic.mjs` | 盤面検証、複製、十字反転、全消灯判定、1操作の状態遷移 |
| `stages.mjs` | 固定6ステージと初期盤面の安全なコピー |
| `progress-store.mjs` | 進捗検証、読込、保存、クリア時更新、例外フォールバック |

## 3. 画面と遷移

画面状態は `TITLE / SELECT / PLAYING / CLEARED / ALL_CLEARED` の5種類とする。静的データ不正時のみ安全停止用の`ERROR`表示を使用する。

```text
TITLE → SELECT → PLAYING → CLEARED → PLAYING
  └────────────→ PLAYING ─────────→ ALL_CLEARED
PLAYING / CLEARED / ALL_CLEARED → SELECT
SELECT → TITLE
```

- `PLAYING`以外の盤面入力は無効。
- ロック中ステージは開始不可。
- 一覧へ戻る・再読込では途中盤面と手数を破棄する。
- 回転・タブ切替では、ページが再読み込みされない限り現在状態を維持する。
- S01〜S05クリアでは次を解放し、S06クリアでは全制覇を表示する。

## 4. 状態管理

| 状態 | 形式 | 保存 |
| --- | --- | --- |
| `screen` | 画面状態文字列 | しない |
| `activeStageId` | `1..6` または`null` | しない |
| `board` | 0/1の正方形二次元配列 | しない |
| `moveCount` | 非負整数 | しない |
| `highestUnlockedStage` | `1..6` | する |
| `bestMoves` | ステージID別の正整数 | する |

保存キーは `daily-mini-games:0002:progress:v1`。保存JSONは`schemaVersion:1`、`highestUnlockedStage`、`bestMoves`のみを持つ。保存はステージクリア時だけ行い、読込・書込失敗時もメモリ上でプレイを継続する。

## 5. 盤面ロジック契約

- `validateBoard(board,size)`：正方形、サイズ、値0/1を検証。
- `cloneBoard(board)`：外側と各行を共有しないコピーを返す。
- `toggleCross(board,row,column)`：入力を変更せず、自身と上下左右だけ反転した新しい盤面を返す。
- `isSolved(board)`：全セル0のときだけ`true`。
- 不正形状は`TypeError`、範囲外座標は`RangeError`で拒否し、入力を変更しない。

## 6. 固定ステージ

| ID | サイズ | 初期盤面 | 検証用操作（0始まり） |
| --- | ---: | --- | --- |
| S01 | 3×3 | `010 / 111 / 010` | `(1,1)` |
| S02 | 3×3 | `110 / 101 / 011` | `(0,0) (2,2)` |
| S03 | 3×3 | `011 / 101 / 111` | `(0,1) (1,0) (2,2)` |
| S04 | 4×4 | `0111 / 1101 / 0011 / 0010` | `(1,1) (2,2) (0,3)` |
| S05 | 4×4 | `1111 / 1001 / 1001 / 1111` | `(0,0) (0,3) (3,0) (3,3)` |
| S06 | 4×4 | `1011 / 0011 / 1100 / 1101` | `(0,1) (1,3) (2,0) (3,2) (1,1) (2,2)` |

固定データは凍結し、開始・やり直しでは毎回コピーを取得する。問題の追加・差し替え・簡略化は行わない。

## 7. 入力・アクセシビリティ

- パネルはネイティブ`button`の`click`へ統合し、タッチ専用の重複ハンドラを設けない。
- Enter／Spaceのキー自動反復を拒否し、通常の1操作は1手だけ加算する。
- パネルは44 CSS px以上、可視フォーカス、`ON/OFF`、`aria-pressed`、行列と状態を含むラベルを持つ。
- 点灯／消灯は色だけでなく、明暗、文字、境界、発光表現で区別する。
- 横スクロールを発生させず、短い横画面では縦スクロールを許容する。

## 9. 例外処理

- 保存読込・書込例外：保存不可を案内し、メモリで継続。
- 破損・未知版・不整合データ：S01のみ解放・ベスト空へ安全に戻す。
- ロック中要求、画面遷移後の残留入力、範囲外入力：状態を変えず拒否。
- 静的ステージ不正：代替問題を生成せず`ゲームを読み込めません`を表示。
