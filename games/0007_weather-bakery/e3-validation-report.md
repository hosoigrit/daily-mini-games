## 検出事項

**E3-F01 — Game #0004のブラウザ回帰スクリプトが再開後の表示を早く判定する。** Chromium 156で既存 `tests/browser-check.mjs` を実行し、通常着地の後に2回目の落下をMISSさせる。MISS演出中に一時停止し、再開すると `second immediate drop reaches GAME OVER` のアサーション（120行目）が失敗する。リポジトリ内の初回とE2基点から展開した隔離コピーで再現した。製品コードに変更を加えない別の観察では、再開後100msで `MISS`・オーバーレイ非表示、400msで `GAME OVER` を確認した。製品側の着地演出は250msで、停止中は進まない。既存スクリプトが再開後100msの固定待ちで表示を判定する点が今回の失敗を説明する。同ブラウザ回帰はFAILのままとし、後続で表示を期限付きポーリングする修正を提案する。Game #0007の動作への影響は確認されていない。

Game #0004のブラウザ回帰FAILは、再開後100msの固定待機に起因する可能性が高い。ただし、現時点では製品不具合とテスト不具合のいずれかを最終確定したものではない。原因分類は、別途承認された是正作業と修正後の再検証を経て確定する。
