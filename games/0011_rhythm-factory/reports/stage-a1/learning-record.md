# Stage A-1 学習記録

- React のレンダーは GameStore の投影を購読する。状態の所有者を固定し、入力による更新、表示、連続描画が互いに再実行を誘発しないようにした。
- 受領した TypeScript 宣言のバイト列を保ち、型の責務をポート単位で参照する。整数時刻と統計用の型を混ぜる例は strict 型検査で拒否できる。
- Strict Mode のセットアップと解除の再実行を計測し、イベント、購読、rAF、テストリソースが1件に収まり、終了時に0件を確認した。
- Vite の相対 base は本番ビルドに適用し、開発サーバーの試験用サブパスは実行引数で指定した。相対 JS/CSS の取得をブラウザで確認した。
- Node と npm をタスク内に固定し、ロックファイルと実インストールを照合した。実行環境の差はブラウザ起動設定として明示した。
- テストダブルで測った挙動は基盤の適用範囲に記録する。音源、判定、保存に依存する統合条件には別の実行証拠が必要となる。
- 独立レビューは、固定された実装コミットを別の実行主体が照合する。実施者、対象、指摘、是正履歴は実行後の台帳に記録する。
