# 次回の承認候補

品質基準を維持した比較の候補を整理する。20 msを超えた実観測は保持し、現行の承認状態も保持する。

| 対象 | 未解決条件 | 推奨する追加承認 | 代替案 |
| --- | --- | --- | --- |
| A2a-CLK-01 Firefox | PulseAudio の接続と有効化は隔離で改善。仮想出力でも長時間同期超過が残る | 同じ Firefox 159.0で、タスク隔離した仮想出力と実音声出力がある専用端末を比較する。CPU予約やオーディオスレッドのスケジューリングを記録し、24秒・84秒を測る | 現行環境のままHOLD。隔離構成を再現手順として保全 |
| A2a-CLK-02 WebKit WPE | 実行可能な公式候補に修正・完全性・対応ドライバーの証拠がそろっていない | 上流修正込みと公式に確認できるブラウザ＋対応Playwrightの組を、既存の npm・ブラウザから分離した比較だけに承認する。採用はその結果を見て改めて判断する | 1.65.1互換かつ来歴とハッシュを確認できる公式配布を待つ |
| A2a-CLK-03 Chromium | 同期残差の段差は再現。ブラウザの出力時計、音声のコールバック処理、実行環境の因果を分離できていない | 固定 Chromium 版で実機と隔離環境を比較する。デフォルト条件の試験を確保したうえで、別条件としてスケジューリング・音声デバイス診断を取得する | 現行HOLDを維持し、時計生データと安全停止を回帰対象に残す |

実機候補は専用の Linux デスクトップで Playwright 管理ブラウザ・物理出力を比較し、Safari が対象の場合は別途 macOS/iOS 実機で計測する。WPE の結果から他の WebKit 実装を判定しない。

実機、プロファイラ、別ブラウザ環境の追加費用は未見積もり。音楽生成 API の費用は0円。比較候補は認証情報のないタスク領域、ループバック、システムにインストールしない構成を前提とする。ドライバーの互換性と配布ライセンスの確認後に、変更内容と復元方法を切り出して承認する。

今回のデータは、製品時計の代替、動的補正、閾値や開始判定の見直しを正当化するところまで達していない。設計変更を検討する場合は、現在の方式で安定実行できるブラウザ範囲、入力判定の検証、実機データを先にそろえる。
