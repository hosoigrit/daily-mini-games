# 84秒の技術検証用音源

固定の試験曲「回転灯」のイベントとシンセ音色を入力にした。120 BPM、4/4拍子、PPQ480で全42小節。12小節を3回配置して、原曲の1〜5小節と12小節を末尾に配置する。全768イベントのIDは固有で、原曲にある6音色と固定シードを使用する。原曲の定義と来歴は同じ Git blob を保持する。

音源合成には既存の Web Audio `OfflineAudioContext` を使う。48 kHz・ステレオ・Float32、4,032,000フレーム/ch、PCM 32,256,000 bytes。実際に返された演奏用 AudioBuffer を全区間走査して有限性、ピーク、音を含む0.5秒区間を確認する。SFX 1音、SFX 4音、BGMとSFXの冒頭100 msの合成ピークは別のオフライン経路で計測する。全区間合成の理論上限は `10 ** (-3/20) + 0.25`。

独立ブラウザ起動で、再生準備後の信頼済み操作から完走までを測定する。CPU診断は通常試行と別に収録する。用いた生成方式、監視条件、停止条件は24秒試験と共通。これは技術検証用 fixture で、正式楽曲の制作物や音質・生成性能の承認資料の代替にはしない。
