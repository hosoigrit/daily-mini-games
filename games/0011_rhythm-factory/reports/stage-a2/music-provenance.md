# Stage A-2 試験楽曲の制作来歴

## 作品と配布範囲

「回転灯」は AG-02（Codex チームの `/root/trial_music`）が Stage A-2 の技術実証用に新規制作した曲です。作曲データと音色は `src/content/stage-a2-trial.ts` に記録しています。来歴 ID は `stage-a2-rotation-beacon-v1` です。

`music-01` と `FAC-01` は承認済みの閉じた型を満たすため、隔離した試験データ上で使用します。曲名、来歴 ID、イベントIDは試験用です。正式楽曲 Happy Assembly の制作・登録、正式コンテンツの品質評価、利用者の正式保存記録への転用は本実証の対象外です。

制作時に用いた素材は、本作業で記述した旋律、ベース、和声、打楽器パターンと音色パラメーターです。既存曲の旋律、サンプル、ダウンロード音源、音楽生成API、外部AI生成サービス、外部音楽ライブラリ、APIキーの利用は各0件です。生成APIへの追加料金は0円です。作曲データはブラウザ標準 Web Audio API の発振器、固定シードのノイズ、ゲイン、フィルター等で合成するためのイベント定義です。

## 音楽と試験キュー

| 項目 | 定義 |
|---|---|
| 拍・長さ | 120 BPM、4/4、480 PPQ、12小節、23,040 tick、24,000,000 μs |
| 生成時の期待フレーム数 | 48,000 Hz × 24秒の1,152,000フレーム／チャンネル、ステレオ。float32のPCM理論容量は9,216,000 bytes |
| セクション | 0起算の0〜1小節がイントロ、2〜5が主部、6〜7が展開、8〜9が高潮、10〜11がアウトロ |
| 調・和声 | Eドリアン。Em(add9)、A6、Gmaj7、Bm7を使用し、終盤はA6からEm(add9)へ着地 |
| 声部 | 三角波主体の旋律、倍音を足したサイン波の鍵盤、低域フィルター付きのベース、低音のキック、帯域を絞ったノイズのスネアとハット |
| 試聴区間 | tick 3,840（4秒）から12秒。定義上の区間は本編の終端内 |
| 持続音 | `a2-lead-02-01` の tick 3,840〜4,560（750ms） |
| 同時発音 | tick 5,760 の `a2-lead-03-01` と `a2-keys-03-01`〜`a2-keys-03-04` |
| 連打キュー | `a2-lead-06-01`〜`a2-lead-06-04` の tick 11,520、11,760、12,000、12,240。250ms間隔 |
| アウトロ | 下降する旋律と打楽器の間引きに続き、最終小節はEを持続。定義上の最終リリースは23,777.083msで終わり、残り約223msは収束後の無音 |

イベントは固定パターンから決定的に展開した222件で、ノイズ用シードは `0xa201120c` です。同じイベント定義を使い、異なるブラウザのPCMバイト同一性は判定条件から除外します。

## データ検査と後工程

承認版Node.jsで曲定義を読み込み、長さ、セクションの連続性、イベントIDと音色IDの一意性、音色参照、tickの整列と範囲、発音長、MIDI値とvelocity、試聴区間、リリース終端、3種類の試験キューを検査しました。対象TSファイルのESLintも実行し、終了コードはともに0です。イベント定義を `JSON.stringify` したUTF-8バイト列のSHA-256は `0fdf2c2522f565c97febd8d046be0ed6830e4971fcdae95b974f22b01b3233fb` です。この値はPCMのハッシュと区別します。

このデータ確認に関連する契約は IF-01、AT-083、TC-D4-001 の試験曲で適用できる部分です。Web Audioでの実生成、ピーク、無音区間、実行時間は別の検証結果を参照してください。正式5曲を求める TC-D5-003 全体は NOT RUN です。主観試聴は AG-02 の作業では行っていません。
