# A2a-PERF-01　最長84秒音源の冷生成性能

重要度 HIGH、状態 OPEN。R2のクラウド実行では同一の84秒負荷fixtureの冷生成が Firefox 3.545〜3.650秒、WebKit 36.981〜40.862秒、Chromium 41.586〜47.602秒だった。

次回の実機検証では、同じ条件の84秒冷生成を3回実施する。各試行で新しい音声アダプターを使い、元の OfflineAudioContext レンダラーが返したバッファを観測する。生成開始・完了を Performance 時刻で記録し、再生時間とは分ける。

| 基準 | 値 |
| --- | --- |
| 冷生成中央値 | 3回で5秒以下 |
| 冷生成最大 | 10秒以下 |
| 保持する選択音源 | 1曲 |
| 同時生成 | 1件 |
| ホールド対象の原本 | 84秒、4,032,000フレーム/ch、48 kHz、2ch Float32 |

PCM容量32,256,000 bytesは上記のデータ形式で算出する。端末全体のメモリ測定は未実施。波形の有限性、−3 dBFSのピーク、音のある区間、解放状況を各試行の証跡に含める。物理端末結果は5環境すべてNOT RUN。今回の実機準備と、正式楽曲5曲の性能合格は別々に扱う。
