# CR-0011-02 判定結果に連動したノーツの消失

固定起点は `ffa0ab232013770ea81ff952c83993338f3cdcde`、tree `3b1021366645a38f1f755cad0c8c339af80c011f`。成功とMISSで見た目を区別する利用者要望に基づき、Canvas描画を変更した。

- Canvasは既存の `RenderSnapshot` と各 `RenderNote.state`・`judgement` を読む。PERFECT・GREAT・GOODはRESOLVEDからマーカーを描画しない。既存の判定表示はそのまま使う。未解決マーカーの中心は判定線まで移動し、配送待ちを含めて線で待つ。空打ちと物理入力による発光はマーカーの成功状態に使わない。
- MISSをCanvasが初めて受け取ったフレームの共通判定時計を表示基準にする。すでに正解時刻を過ぎたマーカーは線から落ち、未来の終了マーカーは当時の位置から進む。既存の描画速度を使い、画面下へ向けて減光する。時計の経過分で位置を直接計算する。基準の保存は描画内だけで、同じセッションの停止・再保持・世代切替をまたいで維持し、新しいセッションで破棄する。
- HOLD開始が成功した場合は頭部を消し、判定線から終了マーカーまでの残存区間を表示する。正常終了で区間と末尾を消す。開始MISSまたは早期解除では既存の失敗を読み、残存区間と失敗マーカーを減光して落とす。解決済みの成功頭部は表示しない。
- CHORDの接続線は両側が判定待ちの間だけ表示する。各側のマーカーとRAPIDの各打点はそれぞれのイベント結果に従う。正式演奏と練習は同じ描画を使う。

既存描画テストでは、未判定TAPの通過座標、HOLD頭部と残存区間の高さ、未判定頭部を線下まで描画していたケースの期待値を変更した。時計の式、線描画、上端クリップ、ノーツ形状、リサイズ・DPR、描画ライフサイクルの検証範囲を維持した。失敗時の下端クリップと減光は新規ケースで確認する。

判定・音声時計・保存、CR-0011-01の48 CSS px入力領域を保全する。製品是正8回、A-2d工程内3/3回、A-2d-R1・CR-R1試験是正各1/1回を維持する。A-2dの技術・工程判定はHOLD。登録、サイト更新および実機受入は別途承認。
