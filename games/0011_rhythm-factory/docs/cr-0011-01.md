# CR-0011-01 判定ライン・入力領域一体化

実機QAで、判定線と離れた下部キーを見比べる必要があると報告された。固定起点は `44d99bd3ee8e3bab0430ad4a58896f3dac3d2e30`（tree `b1d68f64c11aaf24291b20c90b8991ff3e89a505`）。この文書をCR追補とする。

- Canvasと操作領域は同じボードを原点とし、上端から高さの80%を共用する。Canvasの3px線をその座標で中心揃えする。ボードを横に4等分した透明な各48px高のDOM操作領域が判定線をまたぐ。DOMの入力面はCSSピクセルで配置し、Canvasのバッキングストアは既存のDPR処理を使う。
- レーンキーを線の直下に表示する。物理入力は該当する線の発光で、確定結果は既存の判定欄で伝える。再保持時は対象レーンの線を強調する。再保持の案内をボード上部へ置き、判定線のポインター操作を確保する。
- 既存のボタン参照と入力アダプターを再利用する。キー割り当て、Pointer Capture、重複・取消処理、停止と再保持、新世代切替、および判定・音声時計・保存のロジックは固定起点のまま維持する。
- 本番ビルドと画面証跡はローカルに保全する。旧QAサイトの固定3アセット、製品技術判定・工程判定HOLD、既存クラウドFAILを保全する。累積製品是正8回、A-2d工程内3/3回、R1試験是正1/1回の変更はない。物理端末のCR再検証は別途承認後。
