# Game #0005 人間による実機受入手順

この手順は独立レビュー後のG4工程向け。今回の実装担当は実施済みと扱わない。

## 記録する情報

- 実施日時（JST）、担当者、端末機種、OS、ブラウザと版、画面方向。
- 対象ファイルまたは将来承認されたCommit SHA。
- 各ケースのPASS／FAIL／BLOCKED／NOT RUN、スクリーンショット、再現手順。

## 共通手順

1. 承認された安全なローカル配信方法またはレビュー用URLで対象を開く。
2. タイトル→ステージ選択→ステージ1をタップだけでクリアし、ステージ2解放を確認する。
3. 別の挑戦をドラッグでクリアする。指を離した後に終点から再開する。
4. 高速スワイプ、斜め、2本指、画面外への移動、`pointercancel`相当の中断を試す。
5. 戻る、リセット、成功ヒント2回、3回目の拒否、荷物未回収ゴールを確認する。
6. 再読込後にベストと解放だけが残り、途中経路が復元されないことを確認する。
7. 縦横表示、ブラウザUI、スクロール、最小セル、ボタンの押しやすさを観察する。

## 必須端末

- BR-01 Windows PC Chrome
- BR-02 Windows PC Edge
- BR-03 iPhone Safari（公開前必須）
- BR-04 iPad Safari
- BR-05 Android Chrome
- IN-07は各タッチ端末で、盤面内ジェスチャーと盤面外スクロールの両方を確認する。

PCエミュレーションやヘッドレスChromeの結果を、iPhone／iPad／Android実機のPASSへ置き換えない。
