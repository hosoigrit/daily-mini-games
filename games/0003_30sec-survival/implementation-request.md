## IR-01 依頼の目的

正式承認を経て将来実装する場合に備え、宇宙船を全方向へ操作して30秒間隕石を避けるWebゲームの成果物と検証範囲、禁止事項、受渡し条件を明確にする。

**承認済み要件を変更・追加しない。**特に以下は維持する：

- 3ライフ、30秒クリア、残ライフに応じた星評価。
- 360×480論理バトルフィールド、PC WASD/方向キーMust、スマホ固定仮想ジョイスティックMust。
- 隕石は上下左右の画面外から生成され、**生成時の宇宙船位置**へ向かう直線速度を固定。その後は追尾しない。
- EASY/NORMAL/HARDの各段階、初期安全期間1秒、被弾後無敵0.8秒、最低仮想到達時間1.2秒。
- アプリ非表示で自動停止・復帰後は明示再開。手動ポーズボタンはMVP対象外。
- iPhone Safari実機確認が公開前に必須。iPadのみで公開判定しない。

## IR-03 想定実装スコープ（承認後のみ）

### Must

1. HTML、CSS、JavaScriptを中心とする静的Webゲーム。外部サーバー・外部課金・アカウントなし。
2. タイトル、3秒カウントダウン、プレイ、PAUSED、CLEARED、GAME_OVERの状態と画面。
3. 1/60秒の固定更新を基本案としたフレームレート非依存のプレイ時計・移動。
4. 宇宙船の上下左右／斜め移動、斜め速度正規化、フィールド端の衝突半径込み制限。
5. PCのWASD・方向キーとスマホ／タブレットの下部固定ジョイスティック。
6. Pointer Eventsの押下・移動・解放・キャンセル、単一主ポインター管理、入力解除処理。
7. 四辺からの隕石生成、生成時照準・非追尾の直進、画面外削除。
8. 初期安全期間1秒、生成候補の仮想到達時間1.2秒下限、10回までの再抽選とスキップ、段階別同時数上限。
9. 円形接触、3ライフ、被弾隕石削除、無敵0.8秒、同一ステップのライフ減少最大1。
10. 30秒クリア、ライフ0ゲームオーバー、1〜3星、再挑戦時完全初期化。
11. 非表示で自動PAUSED、復帰後手動再開、累積時間・入力のリセット。
12. 画面サイズ／向き／DPRに応じた描画・操作座標整合。
13. DOMで意味のある開始・再開・再挑戦ボタンと、ライフ・残り時間の視認性を確保。
14. ロジックを描画・DOM・保存から分離し、固定入力・擬似時刻・固定乱数で検証可能にする。

### Should（採否を実装前に明示）

- FR-21：同一ブラウザの最高星評価と最長生存時間の保存・表示。
- FR-23：移動方向への宇宙船回転。
- FR-25：PCマウスによる仮想ジョイスティック操作。

Shouldを未採用にする際は削除したことを隠さず、「未採用・理由・後続対応」を報告する。

### 対象外

武器・射撃、複数隕石種、追尾AI、アイテム、ボス、オンラインランキング、サーバー、BGM・効果音の本格実装、派手なパーティクル、手動ポーズ、アプリ化。

## IR-05 設計上の分離責任

| 層 | 担当と責任 | 禁止・注意 |
|---|---|---|
| core | 状態遷移、60Hz更新、移動、出現、衝突、評価 | DOM、Canvas、localStorage、windowを直接参照しない |
| input | キーボード集合、pointerId、方向ベクトル、キャンセル | 移動速度や当たり判定を直接決めない |
| renderer | Canvas背景・宇宙船・隕石・点滅 | ライフ減少・隕石生成などの状態変更をしない |
| main | 画面状態、rAF、各モジュール接続、DOM HUD、保存 | 独立setInterval等で時計を二重管理しない |
| tests | 純粋ロジックの自動試験 | 描画の目視結果を単体テストPASSと偽装しない |

乱数供給と時間ステップをテスト用に差し替えられる構造が望ましい。Canvasの表示座標と当たり判定の論理座標を混同しない。
