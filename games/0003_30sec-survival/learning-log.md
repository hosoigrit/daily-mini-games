## 設計判断

| 判断 | 目的・理由 | 代替案 |
| --- | --- | --- |
| DOM非依存の `core.js` | 時間・入力・乱数を固定した再現可能テスト | Canvas処理に直接ロジックを書く案は不採用 |
| 1/60秒固定更新、1フレーム最大0.25秒 | FPS差で速度・ゲーム時間を変えず、無制限の追いつきを防ぐ | 可変 `deltaTime` 更新は境界が複雑になるため不採用 |
| 到達時間比較に `1e-9` のepsilon | 数学的に1.2秒ちょうどの候補を採用側に保つ | ミリ秒整数化は座標・速度から追加丸めが必要 |
| 被弾更新の次から48更新を保護 | 承認済みの境界定義をそのままコード化 | 被弾更新を1回目に数える案は不採用 |
| キーボード優先、ジョイスティック非加算 | 同時入力時の速度増加・方向競合を防ぐ | ベクトル加算は不採用 |
| Should 3件を採用 | localStorage記録、機体回転、マウスドラッグを外部依存なしで実装可能 | Must優先で見送る案 |

## 実装上の注意

- 隕石速度は生成時の宇宙船座標から一度だけ計算し、以後変更しない。
- 生成予定を現在ステップから再設定し、上限到達や再抽選失敗を後で一括発生させない。
- タブ非表示、フォーカス喪失、pointer終了・キャンセル、画面リサイズで入力を解除する。
- `visibilitychange`と`pagehide`は同じ停止処理を通し、重複発生してもPAUSEDの復帰先を上書きしない。`pageshow`では時計を再初期化するだけで自動再開しない。
- 難易度表示は完了した経過ステップから更新し、隕石生成は更新開始時の段階値を使うことで600／1200境界の表示と生成仕様を両立する。
- 外部画像・音声・フォント・ライブラリは使用しないため、追加素材ライセンスはない。
