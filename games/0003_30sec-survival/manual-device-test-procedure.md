# Game #0003 手動ブラウザ・実機確認手順

自動テスト結果と手動・実機確認を混同しない。各結果には端末、OS、ブラウザ版、画面方向、実施日時を記録する。

## 共通シナリオ

1. タイトルで目的、PC/スマホ操作、開始ボタンを確認する。
2. 開始し、3→2→1の間に宇宙船・隕石・30秒時計が進まないことを確認する。
3. 30秒フルプレイを3回行い、結果、被弾原因、EASY→NORMAL→HARDの体感を記録する。
4. 被弾時にライフが1だけ減り、点滅中の追加接触で減らないことを確認する。
5. 結果画面から再挑戦し、初期状態へ戻ることを確認する。
6. プレイ中とカウントダウン中に別タブ・別アプリへ移り、自動停止、入力解除、明示再開を確認する。

## Windows Chrome / Edge

- WASD、方向キー、斜め、同軸逆押し、キー解放を確認する。
- キー押下中にウィンドウのフォーカスを外し、復帰後に入力が固着しないことを確認する。
- マウスでジョイスティックを上下左右・斜めへドラッグする。
- ブラウザ幅・高さとズームを変え、CanvasとHUD、操作領域の見切れを確認する。

## Android / iPad / iPhone

- 1本目の指でジョイスティックを操作中、2本目の指が方向を奪わないことを確認する。
- 指を領域外へ動かして離す、アプリを切り替える、画面を回転する各操作後に入力が固着しないことを確認する。
- ジョイスティック操作中にページが意図せずスクロールしないことを確認する。
- 縦向き・横向きで表示座標、指の方向、当たり位置が一致することを確認する。

## 公開前ゲート

- iPhone Safari実機は必須。iPadやエミュレーションで代替しない。
- 独立レビューと人間による公開承認が完了するまで公開しない。
