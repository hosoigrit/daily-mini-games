# 3分探偵 v0.6 — デザイン/ロジック仕様

## 承認済みのコンセプト

- 「論理的な犯人特定型」：名前当てでなく、事件に対する犯人の一意性を証拠で立証する。
- 「事件固定・真相変化型」：同じ場所・3人の容疑者でも、3種類の犯人・手段・証拠関係をそれぞれ構築。
- タップ主体の操作、スマホ優先の可読性、制限時間なし、ヒント2段階。
- 同一真相の補助証拠や同じ事実を示す別証拠も受理する。正解を事前開示しない。

## 構造

| CASE | 事件 | 独立した真相数 | 学習テーマ |
| --- | --- | ---: | --- |
| 001 | 消えた青い宝石 | 3 | 開封ログ・本人認証・時刻の逆転 |
| 002 | 流出した未公開原稿 | 3 | 電子送信・紙出力・USB経路 |
| 003 | 止まった時計塔 | 3 | 物理レバー・ソフトウェア設定・部品撤去 |
| 004 | 無許可の入港 | 3 | 紙の発行・電子許可・緊急ゲート開放 |

各真相は、証拠4〜6件・証言3件・事件特有の前提・2段階ヒント・真相説明を持つ。解決用カードは2〜4件。

## 立証判定

1. 提示カードが同じ真相に存在し、重複せず2〜4枚であること。
2. 証拠カードで得られる `facts` の和集合が `requiredFacts` の全要素を含むこと。
3. 人物がその事件の容疑者であり、真相の唯一の犯人と一致すること。
4. 犯人が正しくても (2) を満たさなければ成功しない。
5. 再挑戦中、誤人物と証拠不足では画面に同じ不成立メッセージを表示。

これはあらかじめ検証された因果関係の「証明要件判定」であり、自然言語から未知の事実を動的に導出する一般的な論理証明器ではない。成立する別の論証パターンを増やすには、事件データの事実タグ設計を増補してレビューする必要がある。

## 進行と保存

- 4つの事件から自由に選択。各事件の未解決の真相を優先する。
- 初回クリア記録とベストスコアは別管理。解説確認のみの挑戦は自力解決に加算しない。
- ローカルストレージキーはv0.5互換で維持。未知キー・壊れた値は捨てる。保存不能でも遊べる。
- 中断には確認ダイアログを表示。既存の解決履歴は維持する。

## 公平性のテスト方針

- 事件ごとに前提の完全性・唯一の犯人・他の2人の除外・証拠の独立性をチェック。
- 同じ意味を証明する別カードで正解できることをチェック。
- 関連ない証拠の追加で正解から不正解へ戻らないことをチェック。
- テストの形式的な一意性は「コードで指定された犯人と事実タグ」に対するものに限られるため、自然言語レビューが別途必要。

## v0.7 QA安定化（画面デザインは据え置き）

- 画面再描画時、同一ボタンが存在するならキーボードフォーカスを維持する。
- 「事件の捜査を始める」「推理ボード」「事件一覧へ戻る」「事件解決」の画面遷移時、新しいコンテンツ先頭へスクロールする。

## v0.7.3: IR-01 自力解決と真相開示の分離

- 旧版 `STORAGE_KEY` を維持し、保存データに `revealed: string[]` を追加。旧セーブデータにこの項目がない場合は空配列へ移行する。
- まだ自力解決していない真相で「真相を見る」を確定すると、当該真相IDを `revealed` に保存する。解説表示後は同じ真相を再挑戦しても `solved` / `firstClear` / `best` へ加算しない。
- `solved` の既存達成状態は維持。以前に自力解決した真相の成績更新は許容。別の未開示真相では自力解決の記録が可能。
- 真相選択は `solved ∪ revealed` を体験済みとして扱い、未体験を優先する。全真相体験後は再挑戦を許可。
- ストレージが拒否された場合、セッション内の spoiler flag は維持するが再読み込み後の保全は保証しない。旧v1での真相開示は保存されていないので自動修復できない。

## v0.7.3: IR-02 立証の独立データと限界

- `proof-contracts.mjs` は12真相ごとに `requiredFacts`、決定的な行為の時刻 `moment`、実行者を示す証拠カードと実行者ID `actorEvidence` を独立に定義する。
- `evaluateProof()` は犯人メタデータ `variant.culprit` を正解判定に直接用いず、選んだ証拠の事実と契約内の実行者を照合する。カタログが契約と矛盾すれば `invalid-input` とし、事故的な正解を防ぐ。
- `validateCatalog()` / `validateProofContract()` は、答えと導出人物の不一致、証拠内の人物名や時刻の食い違い、必要事実のズレ、契約未登録を検出する。
- 「手段の唯一性」「記録の信頼性」「行為から犯人を導けるか」の**意味論的な正しさ**までは自動保証しない。第三者による12真相の本文・前提・因果関係レビューを公開前ゲートとする。
