## 5. 人間による確認手順

### PC Chrome／Edge

1. ローカルプレビューURLを開く。
2. スタートを押し、マウスで5回以上命中する。1回ごとに1点増えることを確認する。
3. 空白を押し、得点と位置が変わらないことを確認する。
4. Tabでターゲットへ移動し、Enter／Spaceを長押ししても1押下1点であることを確認する。
5. 別タブへ移動して開始から30秒後に戻り、追加加点なしで結果になることを確認する。
6. リプレイ、自己ベスト、ページ再読込後の初期状態を確認する。

### Android Chrome／iPad Safari

1. PCと端末を同じ信頼できるLANに接続する。
2. Windows Defender Firewall等の設定変更は人間が判断し、必要な場合だけローカルネットワークからNodeサーバーへの接続を許可する。
3. PCのPowerShellで `games/0001_target-tap` ディレクトリへ移動する。
4. PCのLAN内IPv4アドレスを指定して、`$env:PREVIEW_HOST='<PCのLAN内IPv4>'; npm start` を実行する。公開ネットワークやポート転送を使用しない。
5. 実機で `http://<PCのLAN内IPv4>:4173/` を開く。旧URL `http://<PCのLAN内IPv4>:4173/games/0001_target-tap/` は使用しない。
6. 縦・横で開始、5命中、空白ミス、連続10タップ、30秒終了、リプレイ、自己ベスト、回転時の状態維持を確認する。
7. 確認終了後はPC側で `Ctrl+C` を押してサーバーを停止し、`Remove-Item Env:PREVIEW_HOST` で一時設定を解除する。

## 6. 不具合・修正履歴

ゲーム本体の不具合は自動検証で検出されなかった。テストハーネスでは次を修正した。

| ID | 現象 | 原因 | 修正 | 再テスト |

| TH-01 | 一時プロファイル削除がEBUSY | ブラウザ終了前の削除 | 終了待ちと最大5回の削除再試行 | 解決 |
| TH-02 | CDPクラス初期化前参照 | トップレベル実行順序 | 実行本体を関数化し定義後に呼出し | 解決 |

| TH-04 | Edgeで64pxが63.9999847pxと報告 | デバイスエミュレーションの浮動小数点誤差 | 0.01px未満の測定誤差のみ許容 | 解決 |
