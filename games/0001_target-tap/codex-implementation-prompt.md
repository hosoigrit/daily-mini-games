## 2. 一括実装する範囲

**1回の依頼で、実装→自動テスト→不具合修正→最終報告まで実施してください。** ただし重要な仕様変更・アクセス権限の不足・上記承認文書の欠落は例外として停止し、人間に判断を求めてください。

実装対象（承認済み基本設計に準拠）：

- タイトル・開始画面、開始ボタン、30秒のプレイ、結果画面、結果からの即時リプレイ
- 直径**64 CSS px**の円形ターゲットを同時に1個表示。命中まで固定し、命中後に領域内のランダム位置へ再配置
- マウスクリック・タップ・Enter／Spaceで1入力につき正確に+1。ミスは0点。キー長押しやタッチ由来の二重加点を防止
- スコアと残り時間の常時表示、30秒ちょうどの終了判定。タブ非表示中も締切を継続し、復帰後に期限経過していれば結果へ遷移
- `localStorage`で同じブラウザ内の自己ベストを保存・復元。異常値や保存拒否でもゲームを継続
- ページ再読み込み時はREADY・スコア0・タイマー停止で再開始し、保存済み自己ベストだけ復元
- PC・Android・iPhone・iPadの縦横表示に配慮したレスポンシブUIとセーフエリア。画面回転時は残り時間・得点を維持し、必要な場合だけ座標を補正
- CSS・DOM・ロジック・保存の責務分離。外部ライブラリ／フレームワーク／ビルドツールは導入しない

初版にはオンラインランキング、アカウント、効果音、SNS共有、コンボ、難易度変更、端末間の同期を追加しないでください。

## 4. テストと修正（必須）

### 4-1. 自動テスト

外部依存を追加せず、`npm test`（または設計書で合意したNode標準コマンド）で実行できる形にしてください。

- 0点開始、命中+1、ミス0、1操作1加点
- ターゲット1個・64px固定・再配置後の座標が領域内、最低移動距離なし
- 30秒境界（29,999msで採点可能／30,000msで採点不可）、終了処理の一度きり保証
- START連打、リプレイ、前ラウンドのタイマー残留防止
- 非表示状態からの復帰、表示更新遅延後の終了
- `localStorage`の新記録・同点・下回る点数・保存拒否・不正値・ページ再読み込み
- キーボード長押し・マウス・タップ経路の重複加点を防ぐ
- 画面回転・リサイズ時のスコア／締切維持、ターゲット座標補正

### 4-2. ブラウザ・実機テスト

- 可能な範囲でPC Chrome・Edgeを実際に動かして画面・入力・30秒プレイを確認してください。**使用できない環境は未実施と記録**してください。
- エミュレーションでは320×568、375×667、390×844、568×320、1280×720を優先してレイアウトを確認してください。
- Android Chrome実機・iPad Safari実機の確認は人間が後で行えるように、接続方法・手順・期待結果を明記してください。
- iPhone Safari実機テストは**公開前必須**。iPad Safariで先行確認しますが、iPhone実機の代替にはしません。
- iPhoneの`AC-19`～`AC-21`について、ChatGPT／人間が確認できるよう、1項目ずつ「操作手順」「目視で分かる期待結果」を提示してください。人間の報告は「確認できました／不具合あり／未確認」の区分で記録し、**未報告・未実施をPASSと表記しない**でください。
