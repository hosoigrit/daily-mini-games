## 1. ゲームの概要 [必須]

- 一文での説明：30秒間、プレイ領域内に現れるターゲットを素早くクリック／タップし、獲得点数を伸ばす反射神経ゲーム。
- ジャンル：カジュアルアクション／スコアアタック。
- 1プレイの想定時間：約30秒（開始・結果確認を含め約40～60秒）。
- 提供価値・面白さ：操作の分かりやすさ、短時間での達成感、繰り返し挑戦して自分のスコアを更新する楽しさ。
- 学習テーマ：DOM操作、イベント処理、タイマー、ゲーム状態管理、レスポンシブデザイン。
- 初期技術：HTML、CSS、JavaScript。外部フレームワーク／ライブラリおよびビルドツールは原則導入しない。

## 2. 想定プレイヤー [必須]

- 対象：短時間で遊びたいPC・スマートフォン（Android・iPhone）利用者。特定の年齢層やゲーム経験を要求しない。
- 前提知識：不要。日本語の簡潔な操作説明を画面内に示す。
- 配慮事項：スマートフォンの片手操作、誤タップ、視認性、色覚の違い、狭い画面、キーボード／フォーカス操作、短時間プレイ。
- スコアは個人の挑戦記録として扱う。PCとスマートフォン間の入力特性による公平性や世界共通ランキングは対象外。

## 3. 目的と勝敗条件 [必須]

- プレイヤーの目的：制限時間30秒以内に、できるだけ多くのターゲットを命中させる。
- 勝利・クリア条件：明確な勝敗・ノルマは設けない。30秒経過するとプレイが正常終了し、結果を表示する。
- 敗北・ゲームオーバー条件：30秒の時間切れのみ。途中でスコアによって敗北することはない。
- スコア条件 **[TBD-02：A案承認済み]**：有効な命中1回につき+1点。ミス・空白部分のクリック／タップによる減点はない。開始前・終了後の入力は加点しない。
- タイマー **[TBD-05：A案承認済み]**：ゲーム開始操作直後から実経過時間で30秒計測する。別タブへの切替中も時間は経過し、復帰時に終了時刻を越えていれば直ちに終了画面にする。
- ターゲット **[TBD-01・TBD-03：A案承認済み]**：直径64 CSS pxの円形を同時に1個だけ表示する。命中後にランダム座標へ即時再配置し、命中しなければ自動消滅・移動しない。ただし画面回転・サイズ変更で領域外になる場合は、表示領域内への位置補正を許容する。難易度・大きさはプレイ中固定。
- ハイスコア **[TBD-04：B案承認済み]**：ブラウザ内の `localStorage` に自己ベストを保存し、結果画面で今回のスコアと自己ベストを表示する。再アクセスしても同じブラウザ・同じ公開元で記録を参照できる。端末・ブラウザ間の同期やオンラインランキングは行わない。

## 4. 操作方法 [必須]

| 操作 | PC | スマートフォン | 結果 |
| --- | --- | --- | --- |
| ゲーム開始 | 「スタート」をクリック、またはフォーカスしてEnter／Space | 「スタート」をタップ | スコア0・残り30秒から開始し、ターゲットを表示 |
| ターゲットに命中 | ターゲットをマウスクリック | ターゲットを1回タップ | +1点しターゲットを再配置 **[TBD-01・02承認済み]** |
| キーボード代替操作 **[TBD-06承認済み]** | フォーカス可能なターゲットをEnter／Spaceで操作 | 外部キーボード利用時はPCに準じる | 有効な入力1操作を1命中として扱う（キー長押しの自動連打は重複加点しない） |
| ミス | ターゲット外をクリック | ターゲット外をタップ | 得点・ターゲット位置は不変。減点なし **[TBD-02承認済み]** |
| リプレイ | 結果画面の「もう一度」をクリック、またはEnter／Space | 「もう一度」をタップ | 新しい30秒のプレイを即時開始し、前回スコアは引き継がない |

## 7. 対応環境 [必須]

- PC対応：Windows 11のChrome・Edgeの検証時点での安定版。想定画面例：1280×720、1920×1080 CSS px。マウスのクリックを必須とし、開始／リプレイはキーボードで操作できる。
- スマートフォン対応：**Android ChromeとiPhone Safariの双方を必須対応**とし、両環境の実機検証を公開前に必要とする。Android参考候補はユーザー所有のGalaxy S26。利用できるApple製実機は現時点で**iPad**であり、iPhone実機は公開前に確保する方針を承認済み **[TBD-08解決]**。最低320×568 CSS px、代表的な375×667・390×844 CSS pxで縦向き操作を確認する。横向き568×320 CSS pxでも操作可能とする **[TBD-07承認済み]**。
- 対象ブラウザ：PC Chrome・Edge、Android Chrome、**iPhone Safari**。iPad Safariで補助的な実機検証を行う予定。iPhone ChromeとmacOS Safari・Chromeは追加検証候補であり、未検証の環境を「実機検証済み」と表記しない。ブラウザの正確なバージョンと端末情報はテスト実行時に記録する。
- 対象外環境 [任意]：Internet Explorer等のサポート終了ブラウザ。オフライン専用アプリ、ネイティブアプリ。
- **検証区分**：自動テスト、PC実ブラウザ、スマートフォンのエミュレーション、スマートフォン実機は別々に結果を残す。エミュレーション成功を実機確認済みとして扱わない。

## 8. スコープ [必須]

- タイトル／開始、30秒のプレイ、ターゲットのランダム表示、クリック／タップ、得点・残時間表示、結果、リプレイ。
- `localStorage` による自己ベストの保存・復元・結果表示（ゲーム0001の記録に限定）。保存失敗時の継続動作。
- ゲーム状態・タイマーの境界動作と二重入力防止。
- PCとAndroid・iPhone・iPad向けの縦横画面調整・確認、キーボード代替操作。
- 機能要件・受け入れ条件に対応する自動テスト、PC実操作・**Android Chrome実機・iPhone Safari実機テスト**、iPad Safariでの補助検証、テスト記録、独立レビュー。iPhone実機の検証は人間の目視確認・項目別報告方式 **[TBD-08解決]** とする。

- オンラインランキング、対戦、ユーザー登録、ログイン、SNS共有。
- 音楽、効果音、振動、複雑なアニメーション、画像素材の外部調達。
- 難易度選択、レベル制、ターゲットの種類追加、コンボ／減点システム（TBD-02・03承認済みの初版スコープ外）。
- ハイスコアの端末間同期、サーバー保存、ランキング共有。ブラウザ内の自己ベスト保存はスコープ内 **[TBD-04承認済み]**。
- ゲーム実装前の `docs/` 公開、PR作成、Push、マージ、GitHub Pages公開。
